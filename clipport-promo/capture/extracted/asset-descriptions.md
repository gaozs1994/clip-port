# Asset Inventory

- `capture/assets/clipport-icon.svg` - Official ClipPort app icon. A white C-shaped media port around an orange play symbol on teal. Use only at original proportions.
- `capture/assets/clipport-light.png` - 1440x1000 desktop interface capture in the primary light theme. Shows the pasted URL, completed parse, media details, four download presets, format controls, save location, active queue, speeds, and processing states.
- `capture/assets/clipport-dark.png` - 1440x1000 desktop interface capture in dark theme with the same parsed result and queue. Useful for a brief theme continuity or reliability beat.
- `capture/assets/clipport-mobile.png` - 375x812 responsive interface capture. Shows the same paste and parse flow condensed for a narrow viewport.

All three screenshots are direct captures from the current ClipPort prototype and are the product visual source of truth.
